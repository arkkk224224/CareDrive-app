# 케어드라이브 웹 (자녀 앱 · 차량 화면 · 서버)

와이어프레임(Figma 「04최종 와프」)의 화면을 그대로 구현한 Next.js 앱이다. 한 프로젝트에 세 가지가 들어 있다.

| 주소 | 내용 |
| --- | --- |
| `/` | 자녀 모바일 앱 (M-01, C-010 ~ C-078). 휴대폰 브라우저로 연다 |
| `/v` | 차량 화면 (V-000 ~ V-021, 1280×720 기준). Android 앱 `VehicleActivity`가 WebView로 띄운다. `/v?vin=DEMO-AVANTE`처럼 차량을 고를 수 있다 |
| `/api/*` | 서버. 인증, 초대·수락, 하루 요약 수신, 판정, 알림, 삭제 |

## 구성

| 파일 | 역할 |
| --- | --- |
| `lib/judge.ts` | 판정 로직(순수 함수). 기준선 학습(28일·20회), 관찰 알림(−30% 지표 2개 이상이 56일 중 49일), 쿨다운 12주, 제외 기간, 재학습, 길 헤맴(30일 2건), 음성 응답 분류. Kotlin `core/`와 같은 규칙 |
| `lib/db.ts` | Neon 연결, 판정 결과를 알림 표와 맞추는 `sync` |
| `lib/seed.ts` | 가상 계정과 목업 데이터 (11/15 시나리오) |
| `app/api/[...path]/route.ts` | API 전체 |
| `app/child/*` | 자녀 화면. `app/v/page.tsx` 차량 화면과 시연 패널 |
| `schema.sql` | DB 표 정의 |

## 실행

```bash
npm install
# .env.local 에 DATABASE_URL=<Neon 연결 문자열>
npm run dev
npm test        # 판정 로직 테스트 4개
```

## 가상 계정 (시연용)

| 계정 | 내용 |
| --- | --- |
| 자녀 `010-1234-5678` (지수, 딸) | 엄마·아반떼(관찰 알림 11/14 + 길 헤맴 알림 11/12), 아빠·싼타페(평소와 비슷), 할머니·모닝(배우는 중) |
| 자녀 `010-9876-5432` (민준, 아들) | 연결 없음. 초대 → 수락 흐름 시연용 |
| 차량 `DEMO-AVANTE` / `DEMO-SANTAFE` / `DEMO-MORNING` | 지수와 연결된 차량 |
| 차량 `DEMO-GRANDEUR` | 연결 전. 코드 발급 화면(V-000)이 뜬다 |

- 인증번호는 시연용 고정값 `123456`이다(문자 발송 업체 미연동).
- 차량 화면 오른쪽 아래 **시연** 패널: 변속(P·D), 길 이탈 주입, 시동 끄기(운전 1번 기록), "공유 멈춰줘", 다음 날로, 평소 4주·감소 12주 주입, 데모 초기화.
- 시연 날짜는 `meta.today`로 고정한다(초기화하면 2026-11-15). "다음 날로"가 이 날짜를 넘긴다.

## 시연 순서

1. **급성**: `/v?vin=DEMO-GRANDEUR`에서 코드 확인 → 휴대폰 `/`에서 민준 계정으로 코드 입력 → 차량에서 "동의하고 연결하기" → 시연 패널 D단 → "길을 벗어나 맴돈다" → P단 → 음성 질문에 "집이요" → 집 안내(알림 없음) → "다음 날로" → 한 번 더 → 자녀 앱에 길 헤맴 알림과 기억력 검사 코칭.
2. **만성**: 같은 차량에서 "평소 4주" → "감소 12주" → 자녀 앱에 관찰 알림, "왜 알림이 왔나요?", 건강검진 코칭.
3. **신뢰**: `/v?vin=DEMO-AVANTE`에서 "이번 달 자녀에게 공유된 내용" → "공유 멈춰줘" → 자녀 홈이 "공유 멈춤"으로 바뀜 → "연결 끊고 모두 지우기".

## 아직 시뮬레이션인 것

- 변속·경로 이탈·주행 요약 입력(Pleos Vehicle·FusedLocation·NaviHelper 승인 전). 판정과 화면은 실제 코드다.
- 휴대폰 번호 인증(고정 인증번호), 차량 식별(차대번호만), 푸시(앱 안 알림으로 대체), 검진 기관 목록(자리표시 값), 새 차량 수락(자녀 화면에서 확정).
