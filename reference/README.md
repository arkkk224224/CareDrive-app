# Python 기준 구현과 시뮬레이션

케어드라이브 만성 판정 규칙의 기준 구현과, 규칙을 정할 때 돌린 실험 기록이다. Android 앱(`../app`)의 Kotlin 코드가 이 규칙을 옮겨 확장했다. 급성 이탈 감지, 음성 응답 분류, 알림 문구와 최신 검증 수치는 Kotlin 쪽(`../README.md`)에만 있다.

- `caredrive/chronic.py` 만성 채널: 일별 기록 → 28일 창 → 고정 기준선 → 단계 판정
- `caredrive/acute.py` 급성 채널: 이탈 후보 → 정차 시 질문 → 길 잃음 후보 누적
- `caredrive/sim.py` 합성 데이터 시뮬레이션 (성능 입증이 아니라 동작·오경보 확인용)

```bash
cd reference
py -m unittest discover -s tests -t .
py -m caredrive.sim
```

## 규칙 결정: 연속 56일 → 56일 중 49일

연속 56일은 잡음 하루에 카운트가 끊겨 급감 탐지가 70%대였다. 새 시드로 두 번 검증한 뒤 "56일 중 49일 이상 2지표 하락"을 기본 규칙으로 정했다. 현실 노이즈 = 감기·통증으로 7~21일 쉬는 구간(태그 안 함) + 주별 편차 확대 + 월별 생활범위 변동. 표는 오경보 연 횟수 / 탐지율·중앙 지연 (n=200, 현실 노이즈).

**검증 1: 노이즈 크기와 임계 일수 (새 시드)**

| 규칙 | 노이즈 | 정상 | 겨울 | 3%/주 | 급감 -40% |
| --- | --- | --- | --- | --- | --- |
| 연속 56 | 1x | 0.02 | 0.04 | 94%/22주 | 74%/16주 |
| 49/56 | 1x | 0.04 | 0.09 | 98%/20주 | 85%/11주 |
| 52/56 | 1x | 0.02 | 0.05 | 98%/21주 | 83%/13주 |
| 45/56 | 1x | 0.07 | 0.17 | 99%/19주 | 88%/10주 |
| 연속 56 | 2x | 0.04 | 0.07 | 92%/22주 | 69%/12주 |
| 49/56 | 2x | 0.14 | 0.20 | 99%/19주 | 85%/11주 |
| 52/56 | 2x | 0.10 | 0.14 | 98%/21주 | 79%/11주 |

**검증 2: 운전자 유형과 타인 운전 (49/56, 괄호는 연속 56)**

| 조건 | 정상 오경보 | 급감 탐지 |
| --- | --- | --- |
| 가벼운 운전자(하루 0.75트립) | 0.10 (0.02) | 88% (78%) |
| 많이 타는 운전자(1.5트립) | 0.04 (0.01) | 85% (76%) |
| 타인 운전 20% | 0.06 (0.03) | 81% (66%) |
| 타인 운전 40% | 0.07 (0.04) | 74% (57%) |

- 어느 조건에서도 49/56이 탐지를 10~17%p 올렸고, 오경보는 노이즈 2배에서도 연 0.14회로 목표(연 1회 이하) 안이다.
- 52/56은 오경보가 더 적지만 급감 탐지가 79~83%로 떨어진다. 오경보가 문제가 되면 52로 올린다.
- 타인 운전이 40%까지 섞이면 두 규칙 모두 급감 탐지가 크게 떨어진다. 타인 운전 필터(마할라노비스)가 필요한 이유다.
- 1지표만 감소하면 알리지 않는다(트립 수만 -40%: 탐지 9%).
- 합성 데이터라 노이즈 크기는 내 가정이다. 이 수치는 동작 확인이다.

## 야간 운전을 안 하는 운전자 보강 (NIGHT_OFF_MEAN = 0.70)

기준선의 야간 비율이 5% 미만이면 야간 지표를 빼는데, 그때도 "2개 지표 모두 -30%"를 요구하면 3개 중 2개일 때보다 훨씬 엄격해진다. 운전자 유형별로 재 보니 급감 탐지가 크게 떨어졌다(현실 노이즈, n=200).

| 운전자 유형 | 정상 오경보(1회 이상) | 급감 -40% 탐지 (처음 규칙) |
| --- | --- | --- |
| 야간 12% | 4% | 88% |
| 야간 3% | 4% | 66% |
| 야간 0% | 0% | 60% |

지표 평균 방식을 모든 운전자에 쓰면 야간 12% 운전자의 오경보가 3%에서 13~27%로 늘어 손해였다. 그래서 야간 지표를 못 쓸 때만 "2지표 평균 ≤ T2, 둘 다 0.9 이하"로 판정하고, 정상 오경보가 3지표 운전자와 비슷해지는 T2를 골랐다.

| T2 | 야간 3%: 정상 오경보 / 급감 탐지 | 야간 0%: 정상 오경보 / 급감 탐지 |
| --- | --- | --- |
| 처음 규칙 | 4% / 66% | 0% / 60% |
| 0.65 | 4% / 74% | 1% / 70% |
| **0.70 (채택)** | 6% / 86% | 2% / 83% |
| 0.75 | 8% / 94% | 6% / 93% |

야간 12% 운전자는 이 분기를 타지 않아 결과가 그대로였다(정상 4%, 급감 88~91%).

## 알려진 문제: 지표 1개 감소에도 알림이 간다

운전 횟수만 -40% 줄어도 1년 안에 알림을 받는 비율이 현실 노이즈 32%, 깨끗한 데이터 23%다. 트립이 줄수록 야간 트립이 적어져 야간 비율이 크게 출렁이고, 그게 두 번째 하락 지표로 잡힌다. 야간 지표에 최소 표본 조건을 거는 방안이 다음 과제다.
